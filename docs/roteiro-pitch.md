# Roteiro de Pitch (até 3 minutos) - Orbital Alert

## 1) Abertura (hook)
"Imagina receber um alerta de enchente ou incêndio antes da situação sair do controle. Foi para isso que criamos o Orbital Alert."

## 2) Problema
"Hoje, eventos climáticos extremos como chuvas intensas, enchentes e queimadas causam grandes impactos, e muitas vezes as respostas chegam tarde. Falta integração entre monitoramento, análise e ação preventiva."

## 3) Solução
"O Orbital Alert é um MVP que combina dados simulados de satélite com leituras de sensores IoT para monitorar regiões de risco e gerar alertas preventivos. A proposta é simples: transformar dados em decisão rápida."

## 4) Fluxo de demonstração
"Na prática, o fluxo funciona assim: primeiro, o simulador IoT gera leituras de temperatura, nível de água, fumaça e chuva. Essas leituras são enviadas para a nossa API em Spring Boot, que aplica regras de negócio e cria alertas automaticamente quando os limites são ultrapassados. Depois, no app mobile, mostramos os indicadores principais, as regiões monitoradas e os detalhes de cada alerta."

## 5) Tecnologias
"Para construir o MVP usamos PostgreSQL no banco, Java 21 com Spring Boot no backend, Python no simulador IoT, React Native com Expo no mobile e Postman para testes da API."

## 6) Impacto
"Com essa abordagem, conseguimos simular uma plataforma que apoia prevenção de desastres, cidades inteligentes e decisões mais rápidas em cenários críticos — tudo alinhado com o tema Space Economy."

## 7) Fechamento
"O Orbital Alert mostra que, mesmo com um MVP acadêmico, já é possível integrar dados e tecnologia para proteger pessoas e territórios. Obrigado!"
